Observações
Como usar / limitações
  1. Abra sempre pelo NFSe Downloader.bat — abrir o .html direto faz o navegador bloquear a API por CORS.
  2. O certificado digital (A1 instalado no Windows ou A3 no token) precisa estar disponível no computador. O Chrome mostra o seletor de certificado na primeira conexão com adn.nfse.gov.br.
  3. O Chrome memoriza o certificado escolhido até ser totalmente fechado. Para trocar de empresa, feche todas as janelas desse Chrome e abra de novo pelo .bat.
  4. A busca varre o feed inteiro a partir do NSU 0 a cada execução — em caixas grandes isso demora alguns minutos. Você pode clicar em Parar: o que já veio continua listado.
  5. Esta página não envia dados para lugar nenhum: fala só com adn.nfse.gov.br e guarda no localStorage apenas o nome/CNPJ da última empresa detectada.
  6. Notas canceladas: o cancelamento é um EVENTO separado. Como a busca traz o feed inteiro, todo cancelamento existente é reconhecido e a nota correspondente aparece marcada como CANCELADA.
